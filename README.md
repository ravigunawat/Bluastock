# Bluestock - IPO Management Platform

A full-stack IPO management web application 
supporting IPO listing, subscription, 
and allotment workflows.

## Features
- IPO listing and management dashboard
- User subscription and payment handling
- IPO allotment tracking
- Secure CRUD operations

## Tech Stack
HTML, CSS, JavaScript, PHP, SQL

## What I Built
- Normalized database schema for IPO data
- Backend modules for subscription handling
- Responsive frontend pages
for pr test review
